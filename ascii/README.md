# Bundled ASCII Magic files

`pieces/cpu-cores.js` (the Animation widget's default piece) and `lib/kit.js` come unchanged from [ascii-magic-art](https://www.npmjs.com/package/ascii-magic-art) 1.1.0 by ASCII Magic (ascii-magic.com), under the MIT License in `LICENSE` here. Other pieces are downloaded from ascii-magic.com when `ANIMATION_URL` names them, and cached in `~/.claude/visualscan/ascii/`.
